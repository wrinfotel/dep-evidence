## Цель продукта

Бесплатный локальный CLI `DepEvidence` (рабочее имя) для Java/Maven-проектов:
принимает готовый CycloneDX JSON SBOM и собирает воспроизводимый пакет
доказательств по open-source-зависимостям. Основная ценность — evidence
assembly и ручной workflow, а не ещё один vulnerability scanner.

Два первых сегмента:

- небольшая Java/Spring-компания или digital-агентство с enterprise-клиентом;
- небольшая open-source-команда без выделенного AppSec-инженера.

## Утверждённые решения

- Архитектура: локальный CLI + отдельная opt-in синхронизация публичных данных.
- Основной запуск поддерживает `--offline`; исходный код клиента не отправляется
  на hosted service.
- Вход: CycloneDX JSON SBOM; лимит первого контура — до 2000 компонентов.
- OSV matching и CISA KEV идут по локальным snapshot с provenance, timestamp
  и SHA-256.
- CISA KEV означает только присутствие CVE в KEV, но не эксплуатацию именно
  этого Maven-компонента.
- Лицензия без подтверждённого источника остаётся `unknown`.
- Исключения локальные, с причиной и сроком действия.
- Выходы: `report.html`, `evidence.json`, `components.csv`, `exceptions.json`,
  `sources.json` и diff с предыдущим локальным bundle.
- Не обещаем compliance, юридическую гарантию, continuous compliance или
  автоматическое обновление зависимостей.
- Тарифы и цены отложены до реального validation.
- Python 3.11 + стандартная библиотека: сборка и тесты должны идти на текущем
  сервере без Java/Maven.

## Важные ограничения

- Не начинать broad development вслепую.
- Не смешивать SBOM generation, matching, KEV, license, provenance,
  questionnaire и exception workflow в один нераздельный монолит.
- При неуверенности использовать `unknown`/`review`, а не угадывать.
- Перед публичным запуском отдельно проверить лицензии и условия
  OSV/OSV-Scanner/deps.dev/CISA KEV и redistribution snapshots.
- Не удалять проектные файлы и не менять настройки Hermes без явной команды.
